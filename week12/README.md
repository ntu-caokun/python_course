# 机器学习 —— 聚类与降维

## 课前一句话理解

> **聚类**：把相似的东西**自动分成一组**（无监督学习）  
> **降维**：把高维数据**压缩成低维**，同时保留主要信息

两者的共同点是：**都不需要标签数据**。

---

## 1. 什么是聚类？

把数据分成若干组（簇），使得：
- **组内样本**尽可能相似
- **组间样本**尽可能不同

### 特点
- **无监督学习**（不需要标签）
- 计算机自己发现数据中的“自然分组”

### 例子
| 应用场景 | 说明 |
|----------|------|
| 用户分群 | 根据购买行为把用户分成几类（高价值、沉睡等） |
| 新闻聚类 | 自动把相似新闻归到一起（如体育、财经） |
| 图像压缩 | 把相似颜色聚成一类，减少颜色数量 |
| 异常检测 | 离所有簇都很远的点可能是异常 |

### 常见算法
| 算法 | 一句话解释 |
|------|------------|
| **K-Means** | 最常用，预先指定要分成几组，迭代优化 |
| **DBSCAN** | 基于密度，能识别任意形状的簇，自动处理噪声 |
| **层次聚类** | 像树一样不断合并或拆分，不提前指定分组数 |

---

## 2. 什么是降维？

把高维数据（比如100个特征）转换成低维（比如2个或3个），同时**尽量保留原始数据的关键结构**。

### 特点
- 解决“维度灾难”
- 方便可视化（降到2维或3维可画图）
- 去除冗余特征，加速后续模型

### 例子
| 应用场景 | 说明 |
|----------|------|
| 数据可视化 | 将高维数据降到2D/3D画出来看分布 |
| 图像降维 | 压缩图像特征，保留主要信息 |
| 去噪 | 降维可以滤掉一些噪声 |
| 加速聚类/分类 | 降维后数据更紧凑，计算更快 |

### 常见算法
| 算法 | 一句话解释 |
|------|------------|
| **PCA（主成分分析）** | 最常用，找到数据方差最大的方向投影 |
| **t-SNE** | 擅长可视化，能保留局部结构（但计算慢） |
| **UMAP** | 比t-SNE更快，全局和局部结构都保留较好 |

---

## 3. 聚类 vs 降维（一图看懂）

| 对比维度 | 聚类 | 降维 |
|----------|------|------|
| 目标 | 把样本**分组成簇** | 把特征**压缩维度** |
| 输出 | 每个样本的**簇标签**（如1,2,3） | 每个样本的**低维坐标** |
| 改变什么 | 改变样本的**分组归属** | 改变样本的**表示方式** |
| 典型用法 | 分群、分组 | 可视化、加速、压缩 |
| 是否需要标签 | 否（无监督） | 否（无监督） |

> 注意：两者经常**配合使用** —— 先降维（比如PCA），再对低维数据进行聚类，效果更好且更快。

---

## 4. 两个极简代码示例（概念示意）

> 使用 Python + `scikit-learn`

### 4.1 聚类示例（K-Means）

```python
from sklearn.cluster import KMeans
import numpy as np

# 假设有6个点（二维坐标）
X = np.array([[1, 2], [1, 4], [1, 0],
              [10, 2], [10, 4], [10, 0]])

# 分成2个簇
kmeans = KMeans(n_clusters=2, random_state=0)
kmeans.fit(X)

print(kmeans.labels_)        # 输出：[0 0 0 1 1 1]（哪些点是一组）
print(kmeans.predict([[0, 0], [12, 3]]))  # 新点属于哪个簇
```

### 4.2 降维示例（PCA）

```python
from sklearn.decomposition import PCA
import numpy as np

# 假设有100个样本，每个样本有50个特征（高维）
X = np.random.rand(100, 50)

# 降到2维（方便画图）
pca = PCA(n_components=2)
X_reduced = pca.fit_transform(X)

print(X_reduced.shape)  # 输出：(100, 2)
```
