# 第9周：卷积神经网络（CNN）

## 📖 本周内容回顾

上一节课我们学习了**多层感知机（MLP）**——一种最简单的神经网络结构。MLP在处理图像时有一个很大的问题：**参数爆炸**。

想象一下，一张 224×224 的彩色图片，如果直接输入到全连接网络，第一层就需要 `224×224×3 ≈ 15万` 个输入节点，参数量会迅速膨胀到数百万甚至上亿。这不仅训练极慢，而且很容易过拟合。

**卷积神经网络（CNN）正是为了解决这个问题而诞生的。** 它的核心思想是：
- **局部连接**：每个神经元只关注图片的一小部分
- **权值共享**：同一个卷积核在整个图片上滑动使用
- **池化降维**：逐步缩小图片尺寸，提取主要特征

本周我们通过代码实践，构建了一个轻量级 CNN，在 MNIST 手写数字识别任务上达到了 96%+ 的准确率。


## 🧠 核心概念回顾

| 概念 | 一句话解释 | 课堂类比 |
|------|-----------|----------|
| **卷积核** | 一个小矩阵，在图片上滑动提取特征 | 一个"特征探测器"，专门找某种模式 |
| **特征图** | 卷积核滑过图片后得到的结果 | 探测器找到的特征分布图 |
| **通道** | 不同特征图的堆叠，每层存一种特征 | 多个探测器同时工作，每人一份报告 |
| **池化** | 缩小特征图尺寸，保留主要特征 | 把图片缩小，但保留最重要的信息 |
| **感受野** | 输出像素对应输入图片的区域大小 | 神经元能"看到"的原始图片范围 |

## 💻 我们课堂的代码

本节课我们实现了以下结构的 CNN：

```
输入: [28, 28, 1] 灰度图
      │
      ▼
┌─────────────────────────────────────┐
│ Conv1: 1 → 16 通道, 3×3 卷积        │
│ ReLU + MaxPool (28→14)              │
└─────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────┐
│ Conv2: 16 → 32 通道, 3×3 卷积       │
│ ReLU + MaxPool (14→7)               │
└─────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────┐
│ 展平: 32 × 7 × 7 = 1568             │
└─────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────┐
│ FC1: 1568 → 64 + ReLU + Dropout     │
│ FC2: 64 → 10 (输出0-9)              │
└─────────────────────────────────────┘
```

完整代码已放在课程仓库的 `week08-dl-intro/notebooks/03-cnn-mnist.ipynb`。

## ❓ 常见问题

### Q1: 为什么要用池化层？不用行不行？
池化层有两个作用：1）降低特征图尺寸，减少计算量；2）增强模型的平移不变性（图片稍微移动一点，池化后的结果不变）。没有池化层也可以，但网络会更大、更慢、更容易过拟合。

### Q2: 卷积核的初始值是怎么来的？
随机初始化。训练过程中，卷积核的值会通过梯度下降自动调整，逐渐变成能够检测特定特征（边缘、纹理等）的"探测器"。

### Q3: 为什么第一层卷积核用 3×3，不是 5×5？
3×3 是目前最主流的选择，因为两个 3×3 堆叠的感受野等于一个 5×5，但参数量更少（2×9=18 vs 25），计算效率更高。

### Q4: 我的笔记本跑不动怎么办？
我们已经做了优化：
- 只用了 3000 张训练图片（完整版是 60000 张）
- 网络参数量控制在 10 万左右
- 训练 5 轮约 1-2 分钟

如果仍然卡顿，可以进一步减少训练图片数（如改为 1500 张）。
